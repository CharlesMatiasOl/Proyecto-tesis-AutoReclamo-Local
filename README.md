# AutoReclamo — Gestión de Reclamos Automovilísticos

Plataforma full stack para centralizar y agilizar la gestión de reclamos de terceros (siniestros), con carga de reclamos, seguimiento y panel administrativo para control operativo.

## Funcionalidades
- **Sitio público**
  - Presentar reclamo (formulario multi-paso)
  - Seguimiento por número/código
  - Contacto
- **Panel Admin**
  - Dashboard con métricas
  - Gestión de reclamos por estados (Ingresado, En revisión, Aprobación, etc.)
  - Gestión de clientes
  - Comentarios/bitácora
- **Backend**
  - APIs REST
  - Validación de datos
  - Persistencia en base de datos relacional

## Stack
- Frontend: (HTML-CSS-JS)  
- Backend: Node.js + Express  
- DB: MySQL    
- Herramientas: Git/GitHub, Postman

## Requisitos
- Node.js (versión recomendada: 18+)
- Base de datos (MySQL o PostgreSQL según tu setup)
